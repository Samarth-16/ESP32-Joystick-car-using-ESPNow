\# ESP32 Joystick Car using ESP-NOW



A wireless robot car controlled using two ESP32 boards and ESP-NOW.



\## Features



\- Wireless ESP-NOW communication

\- Joystick-based control

\- Forward, Reverse, Left and Right movement

\- Smooth speed control

\- Automatic stop when signal is lost



\## Components



\- ESP32 DevKit V1 ×2

\- L298N Motor Driver

\- Joystick Module

\- DC Motors

\- Robot Chassis

\- Battery Pack
